---

### Slide 2: Problem Statement & Objectives
- **Problem**: Need for hands-free system automation and real-time intelligent voice interaction.
- **Objectives**:
  1. Capture microphone audio and convert speech to text.
  2. Synthesize clear offline voice responses.
  3. Execute automated system actions (Open Apps, Math Solver, System Metrics).
  4. Generate multi-topic Google & Web Search Reports.
  5. Provide a futuristic Glassmorphism Web Control Center.

---

### Slide 3: System Architecture & Tech Stack
- **Python 3.13**: Core engine and logic routing.
- **SpeechRecognition & PyAudio**: 31-channel microphone audio capture & Google STT transcription.
- **pyttsx3 & Web Speech API**: Dual-engine text-to-speech voice synthesis.
- **Flask REST API**: Web backend endpoints (`/api/command`, `/api/status`, `/api/listen`).
- **Web Interface**: Dark Glassmorphism UI, Web Audio API sound effects, canvas waveform visualizer.

---

### Slide 4: Speech Recognition & Response Pipeline
- **Step 1: Audio Capture** ➔ Microphone stream captured via PyAudio or browser Web Audio.
- **Step 2: Speech-to-Text** ➔ Converted to text transcript string via SpeechRecognition.
- **Step 3: Intent Routing** ➔ Matches command against pattern rules.
- **Step 4: Action Execution** ➔ Launches app, solves math, or fetches search reports.
- **Step 5: Spoken Response** ➔ Audio spoken out loud via speakers and browser voice.

---

### Slide 5: Core Functional Features
- 🕒 **Time Engine**: Tells current time and date in 12-hour AM/PM format.
- 🖥️ **App Launcher**: Opens Notepad, Calculator, Command Prompt, MS Paint, File Explorer.
- 🧮 **Math Solver**: Solves word math problems and algebraic expressions.
- 📰 **Search Reports**: Compiles Wikipedia summaries and Google Search Reports.
- 📊 **System Stats**: Monitors host CPU load % and RAM usage.
- 😄 **Jokes Module**: Generates programming and general jokes via pyjokes.
