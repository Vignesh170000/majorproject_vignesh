AI-BASED VOICE ASSISTANT (ARIA)

An intelligent speech recognition, text-to-speech synthesis, system automation, and web search intelligence system with interactive Glassmorphism control center.

Python 3.13 SpeechRecognition pyttsx3 TTS Flask REST API PyAudio (31 Mics) Google Search Reports Glassmorphism UI
PROJECT BACKGROUND
1. Executive Summary & Industry Context
💡 Industry Evolution
Voice user interfaces (VUIs) have transformed digital computing. Assistants like Google Assistant, Apple Siri, and Amazon Alexa enable hands-free task execution, boosting productivity and accessibility for users worldwide.
🎯 Project Purpose
This project designs, builds, and deploys a complete AI-powered Voice Assistant (ARIA) simulating real-world smart assistant capabilities: audio listening, vocal speech-to-text, intent routing, desktop application launching, and live search reports.
🚀 Key Differentiator
Combines a local host Python engine (`voice_assistant.py`) with a futuristic web control dashboard (`app.py`), offline/online dual voice synthesis, live host CPU/RAM monitoring, and on-screen interactive Glassmorphism Notepad and Calculator modals.
TECHNICAL CHALLENGES
2. Problem Statement & Scope
🎙️ Audio Processing
Capturing microphone audio reliably across various operating systems and handling hardware channel detection without system crashes.
🧠 Intent Router
Parsing user intent accurately between time queries, math expressions, application launches, and multi-sentence web searches.
🖥️ GUI Accessibility
Providing both a standalone terminal CLI and an ultra-interactive Web Control Center with audio waveform canvas animations.
PROJECT REQUIREMENTS
3. Core Functional Objectives
1. Speech Recognition (STT)
Capture real-time voice input from host or browser microphone and convert to transcript strings via Google STT API.
2. Text-to-Speech (TTS)
Deliver audible spoken responses through computer host speakers (`pyttsx3`) and browser voice (`SpeechSynthesis`).
3. System Automation
Launch local applications (Notepad, Calculator, CMD, Explorer, Paint) and web portals (YouTube, Google, StackOverflow).
4. Search Intelligence
Extract Wikipedia summaries and compile multi-topic Google Search Reports with title and snippet cards.
SYSTEM DESIGN
4. 3-Tier System Architecture & Data Flow
Layer / Tier Components Used Operational Functionality
1. Core Voice Engine `voice_assistant.py`
`SpeechRecognition`, `pyttsx3`, `PyAudio`		 Hardware microphone capture, Speech-to-Text transcription, TTS voice engine synthesis, intent parsing, math solving.

SPEECH PROCESSING
5. Audio Capture & Speech Recognition (STT)
🎤 PyAudio 31-Channel Detection
Integrated `PyAudio-0.2.14` allowing Python to enumerate and access 31 system microphone hardware input channels on Windows (`Microphone Array (Realtek)`).
🌐 Browser Web Audio Fallback
Frontend `app.js` uses `navigator.mediaDevices.getUserMedia({ audio: true })` to prompt for browser microphone permissions, with seamless fallback to host server mic (`/api/listen`).
VOICE SYNTHESIS
6. Dual-Engine Text-to-Speech (TTS)
🔊 Host Engine (`pyttsx3`)
Offline TTS engine executing on Python server host. Configured speech rate (175 WPM) and volume (1.0) for clear speaker playback.
🗣️ Browser Voice (`SpeechSynthesis`)
Web Speech API synthesis running inside user browser for instant local audio playback alongside server TTS.
COMMAND ROUTING
7. Intent Router & Command Execution
Intent Pattern Sample Command Trigger Executed Module / Action
Time & Date "What is the current time?" Returns current 12-hour AM/PM time and formatted date.
Math Solver "Calculate 144 divided by 12" Evaluates algebraic word problems safely.
App Launcher "Open Notepad" Launches desktop app & opens interactive on-screen modal.
Search Report "Describe me about Artificial Intelligence" Compiles multi-source Google Search Report cards.
System Stats "Show system status" Queries psutil for real-time CPU load % and RAM usage.
